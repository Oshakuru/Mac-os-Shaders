Metal v1.0: what changed

Work on Metal-v1.0.zip, an Iris shader pack for Minecraft, tuned for Apple Silicon. No shader code changed; the edits are textures, menu labels and docs.

Analysis

  • Reviewed all 110 shader entry points and the shared library code (about 1,600 lines). It was already tightly factored, with no unused functions or settings.
  • Built a test that preprocesses every shader across 57 setting combinations (6,270 builds, no errors) to prove an edit leaves the output identical.
  • Tried replacing repeated conditions with shared flags. It saved about 300 bytes and added lines, so I reverted it.

Size

  • Recompressed the 7 PNG textures losslessly; every pixel matches the original.
  • The zip went from 5.7 MB to 4.85 MB, about 15% smaller.
  • The cubic sun and moon textures are all-rights-reserved. Only their compression changed, but keep that in mind if you redistribute.

Performance labels in the menu

Each heavy option now shows its cost, colored green for low, yellow for medium and red for high. Only the display text changed; defaults and presets behave as before.

Setting names were already colored by impact, so I left them. Ambient occlusion only has two quality steps; its low tier is the separate on/off toggle.

Renamed style

  • The visual style called "Default" is now "Vanilla" in the menu, README and release notes. It was already the pack's default (value 0).
  • The existing "Vanilla" cloud option is untouched, so there are now two options with that name.

Files

  • Metal-v1.0.zip: the updated pack.
  • Metal-v1.0.zip.txt: matching settings file with VISUAL_STYLE=0. It replaces the earlier Dark Fantasy file.
  • Both need the dotted names and must sit next to each other in shaderpacks.

Questions answered

  • Ambient occlusion: darkens corners and creases using the depth buffer. Off in the Air and Pro presets, on in Pro Max.
  • Godrays: the pack already has them as Sunbeams (Atmosphere, then Sunbeams). Raising sunbeam strength to 0.22 and quality to 6 or 8 steps is the cheapest way to make them stronger. A separate screen-space version is possible but unmeasured.

Not tested in Iris and no frame rates measured. Check the labels, colors and performance in-game.
