# Session log — 12–13 November 2026

Working session with Claude on branch `rebrand-macos-shaders-1.0`. A summary, not a transcript. Per-version detail: `docs/VERSION-HISTORY.md`.

## Decisions

- **Rebrand:** Metal is now **macOS Shaders** (spelled "macOS"). Not affiliated with Apple; GLSL/Iris pack, not an Apple Metal renderer.
- **Versioning:** every added feature adds 0.1; full stable releases take the next whole number (2.0, 3.0, ...). See `VERSIONING.md`.
  - 1.0 = Metal 1.2 renamed, no rendering changes
  - 1.1 = bloom
  - 1.2 = sunbeam rework, screen-space sun rays, lens flare, sun size
  - 1.3 = new water (current, in development)
- **Not publishing yet.** New test builds only after the author approves the relevant feature.
- **Art target:** Dark Fantasy Visuals 2.0 (Minecraft Marketplace pack). The author prefers the **original Dark Fantasy tones**; a trial warmer palette was reverted.
- **Bloom:** tight glow on light sources only; no wide, blurry haze.
- **Pro preset** = the author's latest saved Custom settings (`config/macOS-Shaders-v1.3.zip.txt`): AO on at 0.32, sunbeams 0.40 with 6 steps, Sky water reflections, half-resolution wet-ground reflections, Dark Fantasy. These are also the shader defaults.

## What changed in code

- **Bloom (1.1):** `composite.fsh` bright-pass to colortex6 (all three dimensions); `final_main.glsl` adds two mip levels (8 taps). Options Bloom / strength / threshold (0.90 default). Off in Air.
- **Sunbeams (1.2), `pro_max.glsl`:** shadow-map shafts now dim shadowed air as well as brightening lit air, have a wider angle and denser air, with strength up to 0.40. Added 16-sample screen-space crepuscular rays towards the sun, a 4-ghost lens flare (5-tap sun visibility), and `SUN_SIZE` (0.75 default) for both the game sun quad and the Cubic sun.
- **Cheaper maths:** shadow-space transforms bracketed as matrix-vector chains in `pro_max.glsl` and `scene.vsh`.
- **Water (1.3):** MakeUp water removed (code, wave texture, LGPL file). New original `water.glsl` / `water.vsh`, with the approach studied from Mellow 3.5 (MIT, credited in `THIRD_PARTY_NOTICES.md`):
  - blended water, no refraction copy
  - depth fog from depthtex1 (`WATER_FOG`)
  - gentle swell in the vertex shader and four-wave procedural ripples
  - Fresnel reflections: 0 Off / 1 Sky / 2 Sky + Shore (one sample) / 3 Screen-space (8 steps)
  - the colortex4 snapshot is only made for modes 2–3
- **Project skills** in `.claude/skills/`: ponytail (6 skills), graphify, shader-programming. All malware-checked; skill files only, no hooks. Superpowers and ECC were rejected.
